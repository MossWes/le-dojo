# Le Dojo — Comment je lance le projet dans Claude Code

1. Je crée un dépôt Git **privé** nommé `le-dojo` et je mets tout ce dossier à sa racine (`BRIEF.md`, `CLAUDE.md`, `annexes/`, `seed/`, `assets/`).
2. J'ouvre ce dépôt dans Claude Code.
3. J'envoie ce premier message :

> Lis `BRIEF.md`, `CLAUDE.md`, toutes les annexes et les fichiers `seed/`. Ne code rien encore. Dis-moi en 10 lignes maximum ce que tu as compris, les points qui te semblent flous, et ton plan pour l'étape 0. Ensuite, attends mon feu vert.

4. À chaque étape, je teste sur mon iPhone ce que Claude Code m'indique, puis je réponds « feu vert » ou je dis ce qui ne va pas.

## Ce que je garde en tête
- Je ne colle jamais un mot de passe, une clé ou un jeton dans la conversation.
- Je valide chaque commande qui touche à mon serveur avant qu'elle s'exécute.
- Construire Le Dojo est une mission de rang C : elle ne passe jamais avant mes missions S et A.
